| Resource | Tag | Notes |
|----------|-----|-------|
| [hermes-wsl-ubuntu](https://github.com/metantonio/hermes-wsl-ubuntu) | production | WSL2 setup |
| [hermes-agent-docs](https://github.com/mudrii/hermes-agent-docs) | beta | Community docs supplement |

**Playbook patterns** (from awesome list):

1. Nightly self-evolution + guardrail evaluation cron  
2. Memory pressure → Honcho / Hindsight / self-hosted backends  
3. Tune session timeout for slow threads  
4. OpenClaw side-by-side migration before cutover  
5. Curate `USER.md` / `MEMORY.md` intentionally
